# タスク完了時のチェックリスト

## 必須実行コマンド（順序重要）
1. **型チェック**: `npm run typecheck`
   - TypeScriptの型エラーがないことを確認
   - エラーがある場合は修正が必要
2. **リント・フォーマット**: `npm run fix`
   - Biomeによる自動修正を実行
   - 手動修正が必要な警告があれば対応
3. **ビルド確認**: `npm run build`（必要に応じて）
   - 本格的な変更の場合はビルドが通ることを確認

## コード品質確認
- [ ] 型安全性: strict モードでエラーがない
- [ ] 命名規約: camelCase/PascalCase/snake_caseを適切に使用
- [ ] 実装パターン: `string | Uint8Array` 入力パターンに従う
- [ ] エクスポート: `src/index.ts` で適切にre-export
- [ ] Node.js標準API: crypto モジュールを優先使用

## ドキュメント更新
- [ ] コード変更時: 対応する `docs/` のMarkdownを更新
- [ ] 新機能追加時: `docs/_template.md` に従ってドキュメント作成
- [ ] README更新: 必要に応じてプロジェクトルートのREADME.md更新

## Git作業
- [ ] 変更のステージング: `git add .`
- [ ] 意味のあるコミットメッセージ: `git commit -m "説明"`
- [ ] 作業の単位: TodoごとまたはLogical changeごとにコミット

## テスト・実行確認
- [ ] 基本動作: `npm run dev` で動作確認
- [ ] エクスポート確認: 新しい関数が正しくimportできることを確認
- [ ] エラーハンドリング: 不正な入力での動作を確認

## セキュリティ確認
- [ ] 秘密情報: コードに秘密鍵やトークンがハードコードされていない
- [ ] 安全なパラメータ: 暗号化関数で適切なキー長・アルゴリズムを使用
- [ ] 入力検証: 必要に応じて入力値の妥当性をチェック
