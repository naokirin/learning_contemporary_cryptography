# 公開記事について

* articles 以下に、Qiitaで公開する暗号理論と技術の記事内容をまとめます

## 対象読者

* 高校数学レベルの数学知識を持つ
* きちんと説明があれば大学レベルの数学表記でも抵抗が少ない
* 暗号技術や理論に興味があるがRSA暗号が素因数分解の困難性にある程度の理解である暗号技術や理論の初学者
* おもにエンジニアであり、実際の技術との関連も知りたい

## 記事の目的

* 各暗号についての仕組みや理論的な概要から、安全性に対する理解やそのための仕組みを把握できる
* 実際の数学的背景（数学的な安全性の論拠、計算量など）や、高速化のためのアルゴリズム、安全性に対する注意点などをキャッチアップできる
* また、実世界のどのような技術に応用されているかも簡単に説明することで、実世界の技術との関連も示す（たとえばSSL/TLSなど）。

## 記事の記述について

* ポイントを抑えるために箇条書きも利用しつつ、基本は文章で記述する
* アルゴリズムの概要が理解できるように、入力パラメータ、出力値、動作を記述し、パラメータや出力値は変数を定義することで、定義を明確にする
* 数学的な背景をしっかりと記述し、抽象的な情報だけでなく具体的な数式等を示す
  
## 記事の構成について

* 第1回　暗号技術の基礎と安全性の考え方
  * 扱うトピック
    * 現代暗号の目的（機密性・完全性・認証・否認防止）
    * 「安全性モデル」の考え方（IND-CPA / IND-CCA、EUF-CMA などの概要）
    * 暗号・ディジタル署名・ハッシュ関数・秘密分散の位置づけ
    * 「計算量的困難性」に基づく安全性
  * 応用例
    * TLS における暗号技術の組み合わせ
    * Git のハッシュ（完全性）
    * クラウドサービスでのデータ分散保存
* 第2回　共通鍵暗号と暗号モード
  * 扱うトピック
    * 共通鍵暗号の概要
    * ストリーム暗号とブロック暗号
    * DES, AES の仕組みと違い
    * 暗号モード（ECB, CBC, CTR, GCM など）と安全性の違い
  * 応用例
    * AES-GCMによるTLS暗号化
    * VPNやディスク暗号化（AES-CTR, XTS-AES）
    * 無線LAN（WPA2のCCMP）
* 第3回　ハッシュ関数とメッセージ認証コード（MAC）
  * 扱うトピック
    * ハッシュ関数の概要
    * ハッシュ関数の安全性（衝突耐性、原像困難性、第二原像困難性）
    * ハッシュ関数の種類（MD4/MD5、SHA-1、SHA-2、SHA-3）
    * メッセージ認証コードの概要と目的
    * メッセージ認証コードの安全性（偽造困難性）
    * メッセージ認証コードの種類（EMAC、CMAC、HMAC）
  * 応用例
    * データ完全性の確認（Git, ファイル署名）
    * TLSのMAC（HMAC-SHA256など）
* 第4回　RSA暗号・分散署名・準同型暗号
  * 扱うトピック
    * RSA暗号の数論的基盤（素因数分解の困難性）
    * RSA暗号の仕組みと高速化（モジュラ指数演算、CRTなど）
    * RSA-OAEPの概要（暗号化の安全性強化）
    * RSA署名の仕組みと安全性
    * RSA-FDH署名とその理論的な位置づけ
    * 分散署名（分散RSA署名、しきい値署名）の仕組みと応用
    * Paillier暗号（加法準同型暗号）の仕組みと安全性
    * 準同型暗号を利用した応用例（特に電子投票システム）
  * 応用例
    * 電子証明書（X.509）とTLSハンドシェイク
    * ソフトウェア配布の署名（Linuxディストリビューション、Apple/Windows署名）
    * 分散署名による秘密鍵の安全な管理（HSM, マルチパーティ計算）
    * Paillier暗号を用いた電子投票・アンケートシステム
* 第5回　離散対数問題に基づく暗号
  * 扱うトピック
    * Diffie–Hellman鍵共有の仕組み
    * 離散対数問題と計算困難性
    * ElGamal暗号とその安全性
    * 楕円曲線暗号（ECDH, ECDSA）の概要とRSAとの比較（鍵長・性能）
  * 応用例
    * TLS 1.3 の鍵共有（ECDHE）
    * ビットコインやイーサリアムでの署名（ECDSA, EdDSA）
    * SSH接続における鍵交換
* 第6回　高機能暗号とその応用
  * 扱うトピック
    * IDベース暗号の仕組みと安全性
    * 双線型ペアリングの基礎
    * 属性ベース暗号、放送型暗号の概要
    * グループ署名・リング署名（匿名性を伴う署名）の概要
  * 応用例
    * 企業や組織での柔軟なアクセス制御（属性ベース暗号）
    * 電子投票やプライバシー保護型ログイン（グループ署名）
    * 暗号資産の匿名送金（リング署名：Moneroなど）
* 第7回　耐量子暗号とこれからの暗号技術
  * 扱うトピック
    * 量子計算機の登場とRSA/ECCの危殆化（Shorのアルゴリズム）
    * NIST PQC標準化プロジェクトの概要
    * 格子暗号（LWE, Ring-LWE）の仕組みと応用
    * その他のPQ暗号（多変数多項式、符号暗号、同種写像暗号、ハッシュベース署名）
    * 実用化の現状と課題
  * 応用例
    * GoogleやCloudflareの実験的PQC導入（TLSのハイブリッド鍵交換）
    * 長期的なデータ保護（政府や金融のアーカイブ暗号化）

## 注意点

* 古典暗号についてはこの記事シリーズに対して興味を抱く多くの読者が興味が少ない内容になりがちなので、必須でなければ極力省略する
* 特定のプログラミング言語でのコードは利用しない
* 専門用語を使う場合は、簡単にでも説明を記載する（ただし、記載以前に出ており、説明済みの用語については不要）
