# 第4回　公開鍵暗号 1（RSA暗号・分散署名・準同型暗号）

## 4.1 RSA暗号の概要
**説明内容**  
- 公開鍵暗号の代表例であるRSAの仕組み  
- 素因数分解の計算困難性に基づく安全性  
- 鍵生成の流れ  
  1. 大きな素数 p, q を選ぶ  
  2. n = p * q, φ(n) = (p-1)(q-1) を計算  
  3. 公開鍵 e, 秘密鍵 d を設定（e*d ≡ 1 mod φ(n)）  
- 暗号化・復号の式  
暗号文: C = M^e mod n
復号: M = C^d mod n



**図解案**  
- 鍵生成の流れ図  
p, q (素数選択) --> n, φ(n)計算 --> 公開鍵e, 秘密鍵d生成


- 暗号化・復号の流れ図  
平文(M) ---> [暗号化: e, n] ---> 暗号文(C) ---> [復号: d, n] ---> 平文(M)

## 4.2 RSA署名と安全性
**説明内容**  
- ディジタル署名の例としてRSA署名  
- 署名: S = M^d mod n  
- 検証: M ?= S^e mod n  
- 安全性: 偽造困難性はRSA問題の計算困難性に依存  
- RSA-FDH署名（Full Domain Hash）による安全性向上  

**図解案**  
- 署名と検証の流れ  
署名: M ---> [秘密鍵d] ---> S
検証: S ---> [公開鍵e] ---> M' == M ?



---

## 4.3 分散署名（分散RSA署名）
**説明内容**  
- 秘密鍵を複数の参加者で分割して保持  
- 各参加者が部分署名を生成 → 結合して最終署名  
- 鍵管理の安全性向上、単一障害点を回避  

**図解案**  
- 分散署名の流れ  
秘密鍵d ---> d1, d2, d3 (分割)
部分署名S1, S2, S3 ---> 結合 ---> 完全署名S



---

## 4.4 準同型暗号（Paillier暗号）
**説明内容**  
- 加算準同型性を持つ公開鍵暗号  
- 暗号文の演算が平文の演算に対応  
- C1 * C2 mod n^2 = E(M1 + M2 mod n)  
- 暗号化・復号の流れ  
暗号化: C = g^M * r^n mod n^2
復号: M = (L(C^λ mod n^2) * μ) mod n


- 安全性: 決定性の計算困難性に依存  

**図解案**  
- 加算準同型のイメージ  
E(M1) * E(M2) mod n^2 ---> E(M1 + M2)



---

## 4.5 準同型暗号の応用例
**説明内容**  
- 電子投票システムにおける集計の安全性  
- 投票内容は暗号化されたまま加算  
- 集計者は復号して結果のみ取得  
- データプライバシー保護の具体例として紹介  

**図解案**  
- 電子投票システムの流れ  
投票者: 投票M ---> 暗号化E(M)
集計: E(M1) * E(M2) * ... ---> E(合計)
結果: 復号 ---> 合計値
